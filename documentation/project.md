Project 3: Smart Inventory Management System
Problem Addressed: Businesses often have inefficient inventory tracking, leading to stock-outs or overstocking.
Description:
 Develop a system to track inventory in real-time, generate alerts for low stock, and produce reports. Students will containerize microservices, use CI/CD pipelines, deploy on Kubernetes, and automate infrastructure with Terraform and Ansible. No AI required — focus is on automation and DevOps practices.
Deliverables:
Inventory tracking service (Dockerized)
Alert service for low stock
Web dashboard for managers
CI/CD pipeline for automated updates
Kubernetes deployment for scalable services
Prometheus monitoring for system and container metrics
Nginx for dashboard access
Terraform scripts for AWS EC2, S3, VPC
Ansible scripts for server/service configuration
Git repository for code and scripts
Tools: Jenkins, Docker, Kubernetes, Prometheus, Grafana, Ansible, Terraform, AWS EC2/S3/VPC, Nginx, Git
